# Atlas Flux — manifeste d’export

Ce dépôt est la **version Atlas Flux active**. Chaque téléchargement ZIP effectué depuis le dernier point de contrôle doit contenir les composants cartographiques deck.gl/MapLibre, les primitives Palladyon intégrées, les données Wikidata/UCDP locales et les améliorations d’interface récentes.

Pour lancer une copie téléchargée : exécuter `pnpm install`, puis `pnpm dev`. Le point de contrôle le plus récent est la référence de la version exportable ; les archives antérieures peuvent contenir l’ancienne maquette Atlas Connect / `carte-deckgl` et ne reflètent pas l’application actuelle.
